# Instagram Clone Website

This project is an **Instagram Clone Website** developed as part of my Git and GitHub learning journey. The main purpose of this project was to understand and practice Git version control concepts while working on a real-world-inspired web development project.

The website replicates the basic look and feel of Instagram, providing a social media-style interface where users can explore a familiar layout and design.

## Project Objectives

- Learn and practice Git and GitHub fundamentals.
- Understand how to initialize and manage a Git repository.
- Practice tracking changes using Git commits.
- Learn how to create and manage branches.
- Understand how to push and pull changes between local and remote repositories.
- Gain hands-on experience with Git version control workflows.

## Git Concepts Practiced

During this project, I practiced the following Git commands and concepts:

- `git init` – Initialize a new Git repository.
- `git add` – Stage changes for commit.
- `git commit` – Save changes to the local repository.
- `git status` – Check the current repository status.
- `git log` – View commit history.
- `git branch` – Create and manage branches.
- `git checkout` – Switch between branches.
- `git merge` – Merge changes from different branches.
- `git push` – Upload local commits to a remote repository.
- `git pull` – Fetch and integrate remote changes.
- `git clone` – Copy a remote repository to a local machine.
